# Rotate an array

Implement `rotateRight`. Return a new array rotated right by `steps` positions.

- Positive steps rotate right; negative steps rotate left.
- Steps may be larger than the array length.
- Do not mutate the input.
- Return an empty array for an empty input.

```sh
npm test
```

Example: `rotateRight([1, 2, 3, 4], 1)` returns `[4, 1, 2, 3]`.
