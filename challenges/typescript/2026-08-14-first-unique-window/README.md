# First unique-character window

Implement `firstUniqueWindow`. Return the first substring of `input` with exactly `size` characters where every character is unique. Return `null` if no such substring exists.

- A window begins at the lowest possible index.
- Treat JavaScript string code units as characters for this exercise.
- Return `null` when `size` is less than 1 or larger than the input length.

```sh
npm test
```

Example: `firstUniqueWindow("aabcbcde", 4)` returns `"bcde"`.
